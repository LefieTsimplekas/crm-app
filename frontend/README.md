# Leads CRM σε React

Η πρώτη φάση μεταφέρει τη σύνδεση, το κύριο μενού και τα κουμπιά ενεργειών σε React. Οι πίνακες, οι φόρμες, οι αναφορές και η διαχείριση Excel επαναχρησιμοποιούν τον υπάρχοντα κώδικα. Το `src/store.js` διατηρεί τις υπάρχουσες κλήσεις στο Supabase.

## Τοπική εκτέλεση

Με Node.js 24 LTS, από τη ρίζα του repository:

```sh
cd frontend
npm ci
npm run dev
```

Άνοιξε τη διεύθυνση που εμφανίζει το Vite και συνδέσου με τον υπάρχοντα λογαριασμό CRM. Η εφαρμογή χρησιμοποιεί το υπάρχον Supabase, οπότε οι αλλαγές που κάνεις με αυτόν τον λογαριασμό αποθηκεύονται στην ίδια βάση.

Για build και τοπική προεπισκόπηση:

```sh
npm run build
npm run preview
```

Τα αρχεία για στατική φιλοξενία δημιουργούνται στον φάκελο `frontend/dist/`.

Οι τραπεζικοί λογαριασμοί συμπληρώνονται προαιρετικά στην προσφορά και χρησιμοποιούνται μόνο για το τρέχον PDF.
